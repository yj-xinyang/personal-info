# 易军 · 个人信息页面

基于 `简历-易军.docx` 生成的现代化个人信息页面，纯 HTML / CSS / JavaScript，无需构建，打开即用。

## 页面内容

- **Hero**：姓名、岗位、基本信息、到岗状态、项目/经验数据概览
- **关于我**：个人简介与基本信息卡片
- **专业技能**：语言基础、后端框架、微服务、数据与中间件、运维工具、前端技术
- **工作经历**：时间线展示郑州优万科技工作经历
- **项目经历**：万合服装供应链平台、智慧健康云管理平台、数据化实验室监控系统
- **个人优势**：四项核心特质
- **联系我**：电话、邮箱、到岗状态

## 特性

- 深色 / 浅色主题切换（跟随系统并记忆选择）
- 滚动入场动画与打字机岗位轮播
- 导航栏滚动高亮（Scroll Spy）
- 完全响应式，适配手机与桌面
- 无外部依赖，可部署到 GitHub Pages / 任意静态托管

## 使用

直接用浏览器打开 `index.html`，或本地启动静态服务：

```bash
npx serve .
```
